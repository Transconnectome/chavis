# 차지욱 교수 철학 에이전트: 연구 근거와 구현 상태

2026-09-14 · 공개용 기술 보고서 · 전체 목표 진행 중

직접 발언에서 검토한 원칙을 현재 글쓰기·평가·리뷰에 적용하는 로컬 에이전트를 구현했다. 원문, 작성자 귀속, 원칙 해석, 적용 결과를 분리하며, 수집 성공이나 형식 검증을 교수 판단 재현 성능으로 취급하지 않는다. 이 공개본에는 비공개 발언·메일·문서 식별자와 개별 사례의 내용이 없다. 기존 상세 조사 기록과 검증 산출물은 로컬 비공개 저장소에 보존했다.

## 연구와 구현의 연결

세 병렬 하위조사에서 공개 1차 문헌과 공식 API 문서를 검토했다. 상세 확인 위치와 한계는 [기억·개인화 연구](research_memory.md), [수집·연결 연구](research_connectors.md), [전사·평가 연구](research_evaluation.md)에 있다. 다음은 설계 선택이며 이 시스템의 실측 우위를 뜻하지 않는다.

| 연구 쟁점 | 구현에 반영한 선택 | 남은 검증 |
|---|---|---|
| 기억의 시간·갱신·유보 | 원문과 해석을 함께 저장하고 출처 변경·철회를 반영 | 전체 자료에서 귀속·추출의 정확도와 누락률 |
| 검색과 개인별 학습의 상충 결과 | 삭제·수정·근거 추적이 가능한 외부 등록부부터 구현 | 의미 검색·학습과의 비교 |
| 인용 존재와 의미적 지지의 차이 | 정확한 인용·해시 검사와 의미 검토를 분리 | 최종 산출물의 사실성·교수 판단과의 일치 |
| 문서 소유권과 실제 작성자의 차이 | 발신 계정·직접 작성 구간·인용·공동 문서를 구분 | 과거 개정과 문장별 저자 복원 |
| 선호와 아첨의 혼동 | 현재 요청·객관적 근거·제공된 rubric을 우선 | 압력 불변성 및 새 증거에 따른 적절한 수정 |

이 선택은 LongMemEval, LaMP, OPPU, ALCE 등 위 연구 문서에서 검토한 방법과 한계를 바탕으로 한다. 다른 벤치마크의 점수를 이 에이전트의 예상 정확도로 옮기지 않았다.

## 저장소에 포함된 기능

- 비공개 SQLite 원문·원칙 등록부, 직접 발언의 정확한 인용과 출처 개정 검사, 후보·검토된 해석·교수 확인의 구분.
- Gmail 전체 스레드 읽기 및 인용문 분리, Drive 문서·댓글·인용 문맥 분리, Teams의 읽기 전용 Graph 경로와 별도 아카이브 귀속.
- 서비스별 pagination·checkpoint·누락 상태, 병렬 갱신, 대형 문서 내부 재개, 사용 중인 근거의 우선 재확인.
- Docs 탭·본문 구조, Slides 표·그룹·노트, Office·PDF 읽기와 선택적 CPU OCR. 지원되지 않거나 일부만 읽은 내용은 별도 표시한다.
- 과제의 원본 입력·rubric 보존, 준비 receipt, 전체 구간 계획과 통합 검토 선언 검사. 구조 통과가 실제 읽기나 의미 이해의 증명은 아니다.
- CLI, 세 클라이언트 스킬 연결, 기존 글쓰기·평가·리뷰 흐름에 현재 근거를 전달하는 연결, 사용자 systemd timer.

실행법은 [도구 README](../../tools/cha_philosophy/README.md), 의미 검증 계약은 [평가 프로토콜](EVALUATION_PROTOCOL.md)을 따른다. 설치·동기화는 외부 메시지 발송 권한을 부여하지 않는다.

Gmail 전체 열거 증거는 2026-09-13 08:52:17 KST의 완료 기록이다. 이후 소규모 overlap 조회의 숫자를 전체 수집량으로 읽지 않는다. Drive의 전일 일회성 수집은 TLS handshake timeout으로 실패했으며, 다음 정기 갱신이 checkpoint를 이어 진행했다. 수거된 transient unit의 `LoadState=not-found`와 기본 성공 값으로 과거 종료 성공을 판정하지 않는다.

## 검사와 아직 적용하지 않은 변경

운영 Python 코드의 전체 검사는 인계 시 **824개 통과**했다. 네트워크·모델 성능을 검증한 결과는 아니다. 실제 과거 업무 세 사례의 제한된 대조에서는 순서를 반전한 여섯 판정 중 동률 5개·기본 조건 선호 1개·개인화 조건 선호 0개였다. 선택된 소표본이며 일반적 우위나 열위를 입증하지 않는다. 새 미래 사례와 교수의 독립 비교 판단이 필요하다.

Gmail의 후속 정정·조건을 추출 입력과 원칙 재사용에 연결하는 추가 수정안은 별도 사본에서 **883개 검사**를 통과했다. 운영 버전에는 아직 적용하지 않았다. [미적용 코드 패치와 절차](../../tools/cha_philosophy/pending/README.md)를 함께 보존했으며, 별도 사본에 패치를 적용한 Python 해시가 검사된 사본과 모두 일치함을 확인했다.

해당 수정안을 위한 비공개 실제 자료 검토는 Gmail 22개 스레드·171개 메시지를 대상으로 했다. 17개 활성 원칙이 이 스레드를 근거로 사용하며, Drive에만 근거한 나머지 1개는 기존 검토를 유지한다. 실제 재조회와 좁은 자격증명 가림을 포함한 별도 DB 검증은 성공했지만 **운영 DB 이관은 미수행**이다. 자동 의존성 연결을 실제 의미 검토나 교수 확인으로 대신하지 않는다.

## 남은 완료 조건

1. 최신 운영 원문·원칙·예외와 비공개 검토 manifest를 다시 대조하고, 미적용 패치와 검토된 thread revision을 안전하게 함께 반영한다.
2. 실제로 관찰된 TLS handshake timeout의 좁은 재시도 처리를 추가 검증한다. 현재 패치에는 이 수정이 없다.
3. Drive 전체 열거와 내용 gap을 끝까지 확인하고, Gmail 과거 관계·별칭 및 Teams 전체 발견 범위를 보완한다.
4. Teams 연결 재인증, 전용 Entra public-client 설정·로그인·무인 갱신 검증을 완료한다. 기존 인증을 우회하지 않는다.
5. 로컬 추론 재시작에 관한 사용자 응답을 반영하고, 별도 미래 과제에서 철학 적용의 유용성과 판단 충실도를 검증한다.

정확한 로컬 위치와 다음 시작점은 저장소 루트 [HANDOFF.md](../../HANDOFF.md)에 있다. Git 푸시는 비공개 원문 DB, 설정·인증, 모델, 설치된 서비스와 실제 평가 산출물을 백업하거나 배포하지 않는다.
