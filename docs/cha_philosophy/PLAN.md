# 차지욱 철학 에이전트 구현 계획

공개용 기술 계획 · 2026-09-14 인계 기준

목표는 Google Drive, Gmail, Microsoft Teams의 직접 발언에 근거하는 갱신 가능한 에이전트를 만들고 연구 글쓰기·평가·리뷰에 검토된 원칙을 적용하는 것이다. 전체 자료 파악과 실제 판단 충실도는 아직 완료되지 않았다.

1. 공개 1차 문헌·공식 API를 기억·연결·평가의 세 병렬 조사로 검토한다. **보고서 작성 완료.**
2. 원문·귀속·개정·정확한 인용·해석 상태를 분리한 비공개 등록부와 수집기를 구현한다. **운영 코드와 부분 실자료 검증 완료.**
3. 초기 검토된 해석을 기존 글쓰기·평가·리뷰 스킬과 연결한다. **CLI·세 클라이언트 연결·입력 보존·구간 감사 구현 완료. 실제 효과 미입증.**
4. 서비스별 checkpoint와 큰 문서 내부 재개를 이용해 지속적으로 수집한다. **timer 운영 중. 전체 서비스·범위 완료는 아님.**
5. Gmail 후속 문맥의 개정을 추출·원칙 재사용에 연결한다. **883개 검사를 통과한 추가 수정안과 비공개 DB 검증 보존. 운영 반영 전.**
6. 남은 인증·내용 누락·원칙 의미 검토를 보완하고, 교수의 독립 판단을 포함한 미래 과제로 개인화 효과를 비교한다. **미완.**
