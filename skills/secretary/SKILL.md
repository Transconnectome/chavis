# Secretary — 할 일 캡처, 캘린더 일정 동시 등록 및 마감 브리핑

진입점은 `chavis-secretary` 하나다(`tools/google_tasks_agent/secretary.py`의 래퍼). 쓰기는 등록(`add`), 캘린더 동시 일정 배정(`schedule`), 완료(`done`), 날짜 지정(`due`), 제목 수정(`retitle`)이며 삭제 기능은 없다. 5분 주기 데몬(`agent.py`)이 Google Tasks와 캘린더를 읽어 Telegram으로 정기 브리핑(08:30, 17:30)과 마감 점검(13:30, 16:30)을 보낸다.

---

## 1. 대화형 일정 배정 및 동시 등록 ("화요일 오후에 할까?", "일정 잡고 태스크 올려줘")

사용자가 특정 작업(예: "원고 보고 고치기", "초록 제출", "제안서 작성")을 특정 요일이나 시간대("화요일 오후", "내일 오전", "수요일 14:00")에 하자고 제안하거나 일정을 잡아달라고 할 때 사용한다.

### 실행 절차

1. **맥락 및 제목 해소**:
   - 사용자가 "이거 원고"처럼 지칭하면 현재 세션의 작업 파일(예: `paper-review` 대상 원고)이나 열린 태스크에서 대상 제목을 특정한다. 불확실하면 원고명을 한 번 확인한다.
   - 제목은 명확하고 간결한 동작형 문구로 잡는다(예: "원고 보고 고치기", "학회 초록 제출").
2. **사전 빈자리 점검 (`--dry-run`)**:
   - 먼저 `--dry-run`으로 캘린더 충돌 여부와 배정 가능한 최적 슬롯을 탐색한다.
     ```bash
     chavis-secretary schedule --title "원고 보고 고치기" --when "화요일 오후" --duration 2h --dry-run
     ```
3. **결과 처리**:
   - **(성공 시, 상태 `dry_run`)**:
     사용자에게 캘린더 빈자리(`slot.label`)와 일정을 안내하고 확정 실행한다:
     ```bash
     chavis-secretary schedule --title "원고 보고 고치기" --when "화요일 오후" --duration 2h
     ```
     등록 완료 후: 확정된 캘린더 시간(예: `9/22(화) 14:00~16:00`), Google Tasks 기한, 다음 Telegram 리마인드 시각을 보고한다.
   - **(충돌 시, 상태 `slot_conflict`, 종료코드 2)**:
     충돌된 기존 일정(`conflicts`)을 사용자에게 알리고 대안을 제시한다.
     예: *"화요일 오후에는 12:00~14:05 이노에듀 회의, 15:00 면담-이승주, 16:00 팀미팅이 있어 2시간 연속 빈자리가 없습니다. 14:05~14:50(약 45분) 동안 진행하시거나, 목요일 오후(14:00~16:00)로 잡을까요?"*
     사용자의 피드백에 따라 시간을 단축하거나 다른 요일로 `schedule`을 재실행한다.

## 2. 단순 할 일 등록 ("google task에 'X' 올려줘")

특정 시간 블록 예약 없이 마감 기한만 태스크에 올릴 때 사용한다.

1. 제목은 사용자가 준 문구를 그대로 쓴다.
2. 날짜를 말했으면 오늘 날짜를 기준으로 `YYYY-MM-DD` 또는 상대 날짜(`today`, `tomorrow`, `fri`)로 전달한다.
3. 실행:
   ```bash
   chavis-secretary add --title "학회 초록 제출" --due 2026-09-25
   ```
   날짜를 말하지 않았으면 `--due` 없이 먼저 등록한다(캡처를 질문으로 막지 않는다).
4. 결과 JSON을 읽고 등록된 제목, 날짜와 요일(`due_label`), `reminders`를 사용자에게 알린다. 날짜 없이 등록된 경우 마감이 언제인지 1회 확인한다.
5. 직후 `chavis-secretary brief --live`로 현재 긴급도 구간(🔴 경과 · 🟠 오늘 · 🟡 이번 주)을 확인한다.

### 종료 코드 2 (결정 요청) 처리

| `status` | 뜻 | 대응 |
|---|---|---|
| `slot_conflict` | 캘린더에 겹치는 일정이 있음 | 충돌 일정 목록을 보여주고, 여유 구간 또는 다른 요일을 제안 |
| `duplicate` | 같은 제목의 미완료 작업이 이미 있음 | 기존 작업 날짜를 알리고, `due`로 맞출지 `--allow-duplicate`로 새로 만들지 확인 |
| `ambiguous` | `done`/`due` 검색어가 여러 작업에 걸림 | `candidates`를 보여주고 선택받음 |
| `not_found` | 일치하는 미완료 작업 없음 | `find`로 비슷한 제목을 찾아 보여줌 |

## 3. 조회 및 우선순위 트래킹

```bash
chavis-secretary brief               # 전체: 지금 · 오늘 남은 일정 · 🔴 경과 · 🟠 오늘 · 🟡 이번 주 · 📧 마감 메일
chavis-secretary brief --scope now   # "지금 뭐 해야 해?" 핵심 1순위 한 줄
chavis-secretary brief --scope nudge # 오늘 일과 종료 전 반드시 닫아야 할 것
chavis-secretary find "초록"          # 검색 (key, 날짜, 구간, 캘린더 연동 여부 포함)
```

- **우선순위 원칙**:
  - 🔴 기한 경과 (14일 이내) > 🟠 오늘 마감 > 🟡 이번 주 마감.
  - 학술 논문/원고/제안서/심사는 최우선 트래킹 대상이다.
  - 마감이 임박했으나 캘린더에 작업 시간이 배정되지 않은 중요 작업은 브리핑 시 우선 권고된다.
- 방금 변경한 내용을 즉시 볼 때는 `--live`를 붙인다(약 12초, 데몬 스냅샷 우회).

## 4. 완료 및 재일정

```bash
chavis-secretary done "원고 보고 고치기"          # 완료 처리
chavis-secretary due "원고 보고 고치기" 2026-09-28 # 기한 연기/변경
chavis-secretary retitle "초록 제출" "학회 초록 최종 제출 (~9/28)" # 제목 및 기한 표기 수정
```

- 사용자가 "다 했어", "끝냈어"라고 하면 `done`, "미뤄줘", "~까지로 바꿔줘"라고 하면 `due`다.
- 제목에 적힌 기한이 새 날짜보다 이르면 `title_deadline_earlier` 경고가 발생하므로, 실제 연기된 것이라면 `retitle`로 제목의 기한도 함께 갱신한다.

## 5. 하지 않는 것 및 주의사항

- **삭제 불가**: 오삭제 방지를 위해 삭제 명령은 없으며, Google Tasks 앱에서 직접 지우도록 안내한다.
- **Telegram 발송 분리**: `agent.py tick`이나 `send-now`는 실제 텔레그램 알림을 발송하므로, 사용자가 "지금 텔레그램으로 쏴줘"라고 요구한 경우가 아니면 임의 호출하지 않는다.
- **Google 인증 만료 알림**: 7일 OAuth 만료 주기에 도달하면 브리핑에 경고가 붙는다. `google_read_failed` 발생 시 `tools/google_tasks_agent/README.md` 절차에 따라 재인증을 안내한다.
